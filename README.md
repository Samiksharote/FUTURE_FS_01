# 🌐 Personal Professional Portfolio Website

A modern and responsive personal portfolio website created to showcase my **skills, projects, education, certifications, and professional experience**.

This project was developed as **Task 1 of my Full Stack Web Development Internship with Future Interns**.

## ✨ Features

* Responsive and modern UI
* About Me section
* Skills and technologies
* Projects showcase
* Education and experience
* Certifications
* Contact section
* Smooth animations
* Mobile-friendly design

## 🛠️ Technologies Used

* **React.js**
* **JavaScript**
* **HTML5**
* **CSS3**
* **Framer Motion**
* **Vite**
* **Git & GitHub**

## ⚙️ How It Was Made

The website was built using **React.js with Vite** and designed with responsive HTML/CSS. React components were used to structure the different sections of the portfolio, while **Framer Motion** was used for animations and smooth transitions.

**Git and GitHub** were used for version control, and the website is deployed using **Vercel**.
